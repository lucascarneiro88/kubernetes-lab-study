# Kubernetes Lab Study

Laboratório pessoal de estudos práticos de **Kubernetes**, desenvolvido para acompanhar e documentar minha evolução durante a realização de um laboratório prático.

## Objetivo

Registrar os conhecimentos, configurações, comandos, testes e aprendizados obtidos durante o laboratório de Kubernetes.

A documentação será organizada por etapas e dias de estudo dentro da pasta `docs/`.
